## 📂 Available Brand Assets
All graphic assets are located within the `assets/_PNGs/FinDashboard/` directory. The following formats have been uploaded and optimized for production:

* **`apple-touch-icon.png`** — Native shortcut icon for iOS/Apple home screens.
* **`favicon.ico`** — Legacy browser tab shortcut file.
* **`icon-32.png`** — Standard 32x32 pixel dashboard interface asset.
* **`icon-192.png`** — Progressive Web App (PWA) standard Android launch icon.
* **`logo-512.png`** — High-resolution splash screen and main application logo.

---

## 🛠️ Usage Implementation

### HTML Integration
To drop these assets into your web project layouts, use the absolute raw content distribution network path:
